# DBeaver Community

## 用途

Azure SQLを含む各種DBへ接続し、SQL実行、データ確認、スキーマ確認などを行うデータベースクライアント。

## メリット

- ExcelよりDB構造を直接確認しやすい
- SQL実行と結果確認を一画面で行える
- テーブル、カラム、制約、リレーションを確認しやすい
- 複数DBを同じ操作感で扱える

## このプロジェクトでの使い方

- Azure SQLの開発環境確認
- Migration後のスキーマ確認
- マスターデータ調査
- SQLの手動検証
- DB設計レビューの補助

本番DBへの直接更新ツールとしては扱わない。接続権限を最小化し、本番変更はMigration / Pipelineを原則とする。

## Excelとの違い

Excelはデータ整理・共有向け。DBeaverはDBそのものの構造とデータを確認・操作する開発者向けツール。DB設計の正本はSQL Project / Migration等に置く。

## 導入判断

優先度: 高。DB設計・調査の開発者用GUIとして利用価値が高い。
