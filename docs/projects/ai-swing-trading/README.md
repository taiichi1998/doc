# AIスイングトレード自動売買システム

> 初版: 2026-11-03 / 段階: 要件定義・安全性検証前 / 投資元本: 100,000円

**目的:** 国内株・国内ETFを対象に3〜15営業日で売買する個人向け自動売買システム。AI分析は説明・候補評価として利用し、**注文可否は決定論的なリスクエンジンで判定**する。

## 主要決定

- **対象:** 国内上場株/国内ETF、現物・ロングのみ、3〜15営業日。
- **証券API第一候補:** 立花証券e支店 API v4r10（無料API/デモあり。重要注文機能・認証条件は確認前）。
- **言語と基盤:** Python、Azure Functions Consumption、Azure Storage、Key Vault、必要最小限のAI API、Bicep、GitHub Actions。
- **リスクモード:**
  - DEFENSIVE: 1取引予定損失0.75%、現金比率を確保、最大同時保有1、月次損失停止5%。
  - AGGRESSIVE: 1取引予定損失1.5%、最大同時保有2、投下資金上限90%、月次損失停止10%。
- **重要:** 損失停止の金額は保証ではない。取引停止・急落・ストップ安で超過損失があり得る。信用/レバレッジ禁止。
- **優先順位:** API実現性検証 → バックテスト → デモ/Paper → 小額Live → 実測後に攻めモード。
- **月額:** 500円以下を運用目標、2,000円はアプリ側のソフト上限。実費はAzure/LLM使用量・為替・ブローカー手数料別途。利益の見込みではない。

## 実取引開始の前提条件

1. API v4r10で保護注文（逆指値など）を**本当に発注・維持できるか**確認。Web画面の機能だけを根拠にしない。
2. 10万円で買える最小売買単位/ETFがあり、手数料込みで戦略が成立するかを検証。
3. 注文の重複防止、認証更新、再起動時照合、キルスイッチ、アラートの故障試験。
4. バックテストの未来情報漏洩・費用・サバイバーシップバイアスを排除し、Paperで4週間以上前方検証。
5. LIVEの初期値はfalse、Ownerのみ手動有効化。安全条件未達なら実口座へ接続しない。
