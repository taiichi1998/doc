## FinOps Professionalの最小ルートと費用上の注意

1. **FinOps Certified Engineer**（Practitionerは不要。どちらか一方が登録条件）
2. **FinOps Certified FOCUS Analyst**
3. **FinOps Certified: AI Value**
4. **FinOps Certified: Technology Value**（5つの学習モジュールバッジが必要）
5. **FinOps Certified Professional**：Professional Contributionを提出し、試験合格

EngineerとProfessionalだけを購入してもProfessional認定は取得できません。FOCUS Analyst、AI Value、Technology Valueの費用も別途必要です。Professionalの$1,999は外部参考価格であって**公式最終見積ではありません**。古い情報にはProfessionalの前提資格・有効期間・言語を現在と違って記載したものがあるため、[FinOps Foundation公式FAQ](https://www.finops.org/training-certification/training-faqs/)を優先してください。

**日本語対応に関する重要な訂正**：FinOps公式FAQによれば、現行の日本語コース・試験はPractitionerのみ。EngineerおよびProfessionalは英語です。非英語母語話者は延長時間を申請できます。

**費用を最小化する判断**：まず無料のFinOps / FOCUS入門を学び、Engineerの試験単体を選ぶ。ProfessionalはFinOps責任者を職務上目指す時に、すべての追加前提資格の総額を確認してから投資する。

## 更新ルール
- 受験申込前に試験コード、言語、税を含む支払総額、再試験・認定更新を公式で再確認。
- AI関連で正式名称・提供状況の検証が済んでいないものは**仮候補**であり、受験料を支払わない。
- Microsoft Expertは「試験合格」と「Expert認定付与」の条件を分けて管理する。
- 既存の取得状況はMicrosoft Learnの個人資格ダッシュボードを正とする。
