## 共通要件

各ページで可能な限り以下を共通化する。

- Subscription
- Resource Group
- Service
- Resource
- SKU
- 管理対象タグ
- 対象期間
- 金額単位

過剰な装飾より、数値の読みやすさ・操作性・保守性を優先する。

## 1. 経営サマリー

### KPI

- 総コスト
- 予算
- 予算差
- Forecast
- 部門実質負担額
- 想定削減額

### グラフ・一覧

- 月別コスト推移：直近12か月
- Department別コスト
- Project別コスト
- 主なコスト増加要因
- 削減候補カテゴリ別集計

Department / Project / 増加要因はTop 5 / Top 10へ固定せず、全件確認可能にする。
金額の大きい順を基本とし、件数が多い場合はスクロールまたは表形式を利用する。

### RG負担ルール

- 実コスト
- 実質負担額
- 会社負担閾値
- 閾値までの残額
- 閾値超過有無
- 閾値超過RG件数

実コストと実質負担額を混同しない表示にする。

## 2. コスト分析

### 初期表示

- 月次をメイン
- 必要時に日次へ切替

### 期間

- 今月
- 先月
- 直近7日
- 直近30日
- 直近3か月
- 直近12か月
- 任意期間

### 分析軸

- Subscription
- RG
- Service
- Resource
- SKU
- Tag

### ドリルダウン

`Subscription → RG → Service → Resource → SKU`

### 比較

- 基本：前月比
- 比較対象月を選択可能
- 前年同月比は初期必須としない

## 3. 削減候補

### 対象

- 未使用リソース
- 低利用 / Right Sizing候補
- Reservation / Savings Plan候補

### 一覧

- Resource
- RG
- 現在コスト
- 推奨内容
- 想定削減額
- 削減率

Reservation / Savings Planは1年・3年の削減額・削減率を比較表示する。

複雑な独自優先度スコアは作成せず、想定削減額の大きい順を基本とする。

## 4. タグ品質

### KPI

- タグ充足率
- タグ不足リソース数
- 不正値リソース数

### 表示

- 不足タグ別件数
- RG別タグ不足件数
- 詳細リソース一覧

詳細一覧：

- Resource
- RG
- 不足タグ
- 不正タグ
- Owner

必須タグ：

- Owner
- Project
- CostCenter
- Environment
- Department
- Service

## 対象外

- コストシミュレーション
- 変更前後比較
- 予算超過原因分析の専用ページ
- 高度なカスタムビジュアルの乱用
- RLS

## 検証

- 各KPIがPhase 04の検証値と一致する
- フィルターが意図した範囲だけへ適用される
- ドリルダウンで数値が不整合にならない
- `Untagged` / `Other` の扱いが一貫している
- Department / Project一覧がTop Nで欠落していない
